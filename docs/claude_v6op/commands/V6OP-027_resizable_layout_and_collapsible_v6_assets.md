## 一、任务性质

这是第一阶段签收后的页面可用性修补，不是第二阶段灰色技能接入，不改后端选股主链。

目标：

1. 页面三栏布局支持左右拖拽调宽；
2. V6 未接通技能资产列表可折叠，需要时再展开；
3. 设置要记忆，下次打开仍保持用户上次的宽度和折叠状态。

---

## 二、必须完成

### 1. 三栏布局左右拖拽

当前页面是左侧控制区 / 中间日志与状态区 / 右侧结果区。

要求：

- 在左栏与中栏之间增加可拖拽分隔条；
- 在中栏与右栏之间增加可拖拽分隔条；
- 鼠标拖动时实时改变三栏宽度；
- 中间区域可变大或变小；
- 左栏、右栏要有合理最小宽度，不能拖到内容不可用；
- 整体宽度不能溢出页面；
- 拖拽过程中不要选中文字；
- 支持窗口 resize 后继续可用；
- 将宽度比例或像素值保存到 `localStorage`，刷新后恢复。

建议键名：

```text
v6op_layout_columns
```

### 2. V6 未接通技能资产折叠

当前左侧 V6 技能资产（暂未接通）灰卡列表太长，影响使用。

要求：

- 将 V6 未接通技能资产做成一个可折叠区域；
- 标题类似：`V6 技能资产（暂未接通）`；
- 默认折叠或按上次状态恢复；
- 展开后显示所有灰卡；
- 折叠后只显示标题与数量，例如 `17`；
- 已接通 live 技能不折叠，仍直接可选；
- 灰卡仍保持 disabled，不得变成可执行；
- 折叠状态保存到 `localStorage`。

建议键名：

```text
v6op_v6_assets_collapsed
```

### 3. 样式要求

- 分隔条要在深色主题下清楚可见；
- hover/drag 时有轻微高亮；
- 不要增加大块说明文字；
- 不要新增页面；
- 不要破坏移动端基本可读性；窄屏可回退为单列或横向滚动，但不能遮挡按钮。

### 4. 验收与测试

至少运行：

```powershell
pytest -q
node --check web/app.js
```

如果现有测试是静态检查，请补充/更新前端静态测试，覆盖：

- 存在两个 resizer；
- 存在 localStorage 宽度保存逻辑；
- 存在 V6 assets collapse toggle；
- 灰卡 disabled 逻辑仍存在；
- `SKILL_CATALOG_GRAY` 仍来自 `/api/skill_catalog`。

不要求 Playwright，本轮不要因为 Playwright unavailable 阻塞。
