帮助文档
压力测试怎么跑
1. 全A PRO 5000：从本地A股名单最多截取 5000 只；这是名单上限，不是问财。
2. 问财 PRO 5000：最多接收问财返回结果 5000 条；少于 5000 拿实际数，多于截断。
3. 全技能硬交集：缠论 + K线 + SMC + 波浪 + 排雷一起卡，结果为 0 很正常。
4. 换技能重跑：会重新启动一轮；K线数据库通常复用，不会自动清掉重拉。
5. 换路径重跑：并行/顺序/混合会重新组合技能；已有K线继续用。
6. 先宽后严：先用少量正向技能 + 排雷跑出池子，再加技能或换路径精算。
7. days 参数：改变 days 会影响 K线取数量、技能分析范围和缓存指纹，不同 days 的结果缓存互不命中。
全局解释层说明
来源层：股票池从哪里来，实际返回多少。
数据层：K线是否就绪，有多少本地 / 新拉 / 失败 / 降级。
技能层：每个技能输入多少、命中多少、哪个技能最先筛空。
路径层：顺序漏斗哪一步清零，并行交集为什么为空。
报告层：最终解释是否完整，下一步建议什么。
