帮助文档

压力测试怎么跑
1. 全A 全量：读取本地 A 股名单，不按档位截断；300 / 500 / 2000 只只作为压力提示。
2. 问财不限档位：自动翻页直到没有新增股票；实际返回数量以问财接口为准，不再按 300 / 500 / 2000 截断。
3. 全技能硬交集：缠论 + K线 + SMC + 波浪 + 排雷一起卡，结果为 0 很正常。
4. 换技能重跑：会重新启动一轮；K线数据库通常复用，不会自动清掉重拉。
5. 先宽后严：先用少量正向技能 + 排雷跑出池子，再加技能或换路径精算。
6. days 参数：改变 days 会影响 K线取数量、技能分析范围和缓存指纹。
全局解释层说明
来源层：股票池从哪里来，实际返回多少。
数据层：K线是否就绪，有多少本地 / 新拉 / 失败 / 降级。
技能层：每个技能输入多少、命中多少、哪个技能最先筛空。
路径层：顺序漏斗哪一步清零，并行交集为什么为空。
报告层：最终解释是否完整，下一步建议什么。
多页面架构说明
策略台：主运行页，配置来源 / 技能 / 路径，启动管道。
输入工坊：提示词矩阵、条件积木、最近使用、策略模板管理。
报告中心：查看历史报告、搜索、载入策略参数。
报告对比：选2~4份报告，对比共同命中、唯一命中、参数差异。
管理中心：本页，历史恢复、缓存清理、问财授权、系统设置。
