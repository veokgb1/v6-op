# 中文问财 Query 种子清单

本文件是给 query_lab 和 Claude 使用的中文金融语义白名单。它的目的不是替代实验结果，而是约束实验起点：实际发送给同花顺问财的 `query_text` 必须是中文金融自然语言。

## 硬约束

1. `query_text` 必须使用中文金融表达。
2. 英文只能用于代码字段、文件名、枚举值、测试编号。
3. 禁止把问财查询语句翻译成英文。
4. 允许保留中文金融语境中的常见缩写：A股、ST、MACD、KDJ、PE、PB、ROE、ETF、BOLL。
5. 每条测试必须同时记录英文路由和中文名称：
   - `astock / 问财选A股`
   - `sector / 问财选板块`
6. 每条实际请求必须保留原始中文 `query_text`，报告中不得只保存英文解释。

## 预检规则

运行实验前必须校验：

1. `query_text` 包含中文字符。
2. `query_text` 不得出现英文整句。
3. 除白名单缩写外，发现英文单词时标记为 `invalid_query`，不请求问财。
4. 如果 query 只有模糊词，例如“强势股”“热门板块”，允许进入危险词反测，但默认 `recommended_usage = manual_only` 或 `forbidden`。

## Natural Language Normalizer 候选规则

这些不是最终规则，只是实验后要验证的候选映射。

- 强势股 -> 今日涨幅大于3%，今日成交额大于3亿
- 小盘股 -> 流通市值在30亿到150亿之间
- 低位强势 -> 流通市值在30亿到150亿之间，近20日涨幅小于20%，今日涨幅大于3%，今日成交额大于3亿
- 放量上涨 -> 今日涨幅大于3%，今日量比大于1.5，今日成交额大于3亿
- 资金关注 -> 今日主力净流入为正，今日成交额大于3亿
- 热门板块 -> 今日涨幅大于3%，今日成交额大于50亿的板块
- 主线板块 -> 近5日涨幅最大的板块，今日主力净流入为正的板块

## 报告语言要求

报告必须中文优先：

- stable_dictionary.md：中文稳定表达字典
- risk_dictionary.md：中文风险表达字典
- parser_boundary_report.md：中文解析边界报告
- p1_p6_recommendation.md：中文 P1-P6 候选建议
- query_normalizer_rules.md：中文自然语言改写规则

英文状态值可以保留，但必须带中文解释，例如：

- `stable / 稳定`
- `unstable / 不稳定`
- `risky / 高风险`
- `failed / 失败`
- `forbidden / 禁用`
