# V6-OP 问财法典驱动输入工坊开发交接

本文档用于交给新的 Claude / Codex 对话框，继续开发 V6-OP 的“问财选A股”和“问财选板块”输入工坊。目标不是继续修补 P1-P6 文本按钮，而是把已实测出来的问财法典接入页面，让用户通过可勾选、可收藏、可编号、可校验的方式生成稳定问财语句。

## 1. 背景痛点

当前策略台和输入工坊已经能跑，但“问财提示词输入”仍然不顺：

- 用户每次都要手打很长的问财语句，通常 20 到 30 个汉字以上。
- 差一个字、一个词，问财返回结果可能完全不同。
- P1-P6 只是快捷文本，不是法典驱动，无法解释“为什么这样问是稳定的”。
- 当前页面不知道问财的边界：哪些词稳定、哪些词危险、哪些词禁止、最多能叠加多少条件、返回结果到底是什么。
- “问财选A股”和“问财选板块”的返回内容不同，不能生硬套同一个 UI 逻辑。
- 现有页面的收藏缺少编号、简称、标签、来源、法典依据，后续复用困难。

这次升级的核心是：用 QueryLab 已经摸出来的“地板 / 天花板 / 返回契约 / 法典”驱动页面。

## 2. 开发目标

### 2.1 精准勾选

把“问财选A股”和“问财选板块”都做成法典驱动的字段矩阵。

不要让用户泛泛点击，也不要让前端凭空生成条件。前端应该从法典文件中读取稳定字段、稳定操作符、稳定时间窗口、稳定组合方式，再生成标准问财语句。

例如问财选A股应支持：

- 时间窗口：今日、近3日、近5日、近20日、近60日。
- 行情字段：涨幅、跌幅、成交额、换手率、量比。
- 资金字段：主力净流入、大单净流入、资金净流入。
- 市值字段：流通市值、总市值。
- 排除项：非ST、非停牌。
- 操作符：大于、小于、之间、为正。

例如问财选板块应支持：

- 板块排序：涨幅排名、成交额排名、主力净流入排名、涨停家数排名、上涨家数排名。
- 返回字段：板块名称、指数代码、涨跌幅、成交额、主力资金流向、涨停家数、上涨家数、换手率、量比、领涨股简称。
- 禁止或弱支持：上涨原因、龙头股、值得关注、最强板块等模糊表达。

### 2.2 收藏与编号

用户勾选完成后，应能保存为可复用模板。

收藏模板至少包含：

- 编号：例如 `ASTOCK-001`、`SECTOR-001`。
- 简称：例如“放量突破小盘”、“主力净流入板块”。
- 类型：问财选A股 / 问财选板块。
- 标准问财语句。
- 标签：激进、保守、科技、资金、趋势、小盘、板块等。
- 法典来源：引用哪个字段、哪个规则、哪个测试组。
- 创建时间、最近使用时间、使用次数。

后续策略台不应只显示 P1-P6，而应能选择这些编号化模板。

### 2.3 AI 润色前置校验

当用户把自然语言交给 Claude 润色时，Claude 不能直接美化文本。必须先通过法典判断边界：

- 哪些表达可直接保留。
- 哪些表达必须标准化，例如“超过”统一成“大于”。
- 哪些表达危险，例如“明显、强势、不错、值得关注”。
- 哪些表达禁止。
- 是否超过条件上限。
- 是否需要拆成两步。
- 最终输出标准问财语句。

也就是说，Claude 的任务不是“写得漂亮”，而是“按法典修成可执行问财语句”。

### 2.4 返回内容接入

问财选A股和问财选板块都已经确认：返回内容不只是一个字符串。

问财选A股返回：

- 股票代码。
- 股票简称。
- 最新价。
- 最新涨跌幅 / 今日涨跌幅。
- 条件触发字段：成交额、成交量、换手率、量比、主力资金流向、市值、行业等。

问财选板块返回：

- 板块 / 指数代码。
- 板块 / 指数简称。
- 指数涨跌幅、成交额、主力资金流向。
- 涨停家数、上涨家数、换手率、量比。
- 部分问法可返回领涨股简称，但不是股票代码。

开发时不要只取 codes。应保留 raw rows 或结构化 rows，用于策略台预览、报告中心展示和后续 pipeline。

## 6. 页面改造建议

### 6.1 输入工坊

输入工坊应成为“法典模板管理器”：

- 左侧：技能类型，问财选A股 / 问财选板块。
- 中间：字段矩阵，按法典生成。
- 右侧：标准问财语句预览、返回字段预估、风险提示。
- 底部：收藏、编号、简称、标签。

### 6.2 策略台

策略台不应继续依赖 P1-P6 文本。

策略台应支持：

- 直接选择已收藏模板。
- 从输入工坊回写到策略台。
- 策略台临时改写后可保存回输入工坊。
- A股模板进入 Phase B。
- 板块模板进入 Phase A。
- Phase A 板块结果如果是板块名，应桥接到 Phase B；如果返回的是股票简称或文本，应按返回契约决定下一步。

### 6.3 AI 润色入口

新增一个“按法典改写”入口：

用户输入自然语言后，Claude / AI 应输出：

```text
原始表达：
...

法典判断：
- 稳定字段：
- 风险字段：
- 禁用字段：
- 是否超过条件上限：
- 是否需要拆问：

标准问财语句：
...

建议收藏编号：
ASTOCK-xxx / SECTOR-xxx
```

## 7. 开发边界

- 只修改 V6-OP：`F:\v.6\v6-op`
- 不修改：`F:\v.6\v6`
- 不修改：V5 / V5.10，只能参考。
- 不自动 promote 法典。
- 不丢弃 QueryLab 已有报告。
- 不把实验报告和普通运行报告混在一起。
- 新增模板和法典数据应独立放在 query_lab 或专门配置目录下。

## 8. 一句话任务描述

把当前 V6-OP 的问财输入，从“P1-P6 文本快捷按钮”升级为“法典驱动的字段矩阵 + 标准问财语句生成器 + 收藏编号 + AI 润色校验入口”。
