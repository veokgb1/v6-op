## 各组结论

### S1（地板基础字段）

**结论：全部稳定**。涨幅、成交额、净流入、换手率、量比、近5日/近20日涨幅均可用。  
返回类型：100% sector_only。Backend：100% zhishu。

### S2（同义词）

**结论：全部稳定**。今日/今天、板块前置/后置、超过/大于、主力/主力资金 均等价。  
推荐标准写法：`今日{字段}{运算符}{值}的板块`。

### S3（条件组合天花板）

**结论：1→5 条件全部 stable**。中文逗号分隔，条件叠加线性稳定。

### S4（风险/禁问）

**结论：**
- 热门板块 / 强势板块 → **truly_forbidden**（返回空）
- 主线板块 / 可能爆发的板块 → **semantic_forbidden**（有返回但不可信）
- 所有 4 条均标记 forbidden，不得自动生成

### S5（情绪维度）

**结论：5/6 stable**。上涨家数、涨停家数、涨停数阈值过滤、换手率+涨停组合均稳定。  
例外：连板股最多 → risky（字段非标准）。

### S6（必须拆分的查询）

**结论：4/6 empty（必须拆分），2/6 risky（sector 忽略"龙头股"返回板块列表）**。  
- "X板块中的股票"类查询全部 empty → must_split=true
- "条件+龙头股"pywencai 忽略龙头股语义，仍返回板块

推荐拆法：
```
Step1 sector: 今日涨停家数最多的板块
Step2 astock: {板块名}中今日涨停的股票
```

### S7（低位回流）

**结论：4/5 stable**。历史弱+今日强组合（近60日涨幅<阈值+今日涨幅/资金/成交额）均稳定。  
失败：近5日主力净流入小于0，今日主力净流入大于0 → **不支持同字段双时间窗口比较**。

### S8（返回对象类型专项）

**结论：**
- 标准TOP-N（涨幅/成交额/涨停家数排名前N）→ sector_only stable
- 最强板块/龙头股/板块中股票 → empty（forbidden/must_split）
- 原因是什么 → pywencai忽略追加文字，返回板块列表（risky）
