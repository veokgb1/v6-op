# 问财选板块 禁用问法字典

**实测日期**: 2026-05-07

---

## 禁用类型 A：pywencai 直接返回空（truly_forbidden）

这些问法 sector 和 zhishu 均无结果，属于 pywencai 语义层不支持。

| 问法 | rc | 原因 |
|------|-----|------|
| 热门板块 | 0 | 过于模糊，pywencai 不识别 |
| 强势板块 | 0 | 过于模糊，pywencai 不识别 |
| 今日最强板块 | 0 | 最强 = 模糊词，无法映射到具体字段 |
| 军工板块龙头股 | 0 | 指定板块名 + 龙头股，sector 不支持此组合 |
| 军工板块中今日涨幅排名前10的股票 | 0 | 板块内个股查询，需拆为 astock |
| 人工智能板块龙头股 | 0 | 同上 |
| 人工智能板块中今日涨幅排名前10的股票 | 0 | 同上 |
| 人工智能板块中今日成交额排名前10的股票 | 0 | 同上 |
| 人工智能板块中今日主力净流入排名前10的股票 | 0 | 同上 |

---

## 禁用类型 B：pywencai 返回结果但语义无效（semantic_forbidden）

这些问法虽然有返回，但返回的是全市场默认列表，不是条件筛选结果，**不可用于自动生成 pipeline**。

| 问法 | rc | 原因 |
|------|-----|------|
| 主线板块 | 19 | 返回全市场 zhishu 默认列表，不等于市场主线 |
| 可能爆发的板块 | 20 | 返回近期活跃板块，不是预测型筛选 |
| 哪些板块值得关注 | 19 | 返回热门板块默认列表，不可信 |
| 热门板块 | 0 | 直接失败 |
| 强势板块 | 0 | 直接失败 |

---

## 禁用类型 C：结构性禁用（must_split）

这些问法在 sector 路由下必须拆成两步。不要在 sector 一次性请求。

| 问法 | 拆法 |
|------|------|
| X板块龙头股 | Step1: 无需查（龙头股需在 astock 中定义）Step2: 问财选A股 + 板块名 + 条件 |
| X板块中今日涨幅前N的股票 | Step1: 确认板块名。Step2: 问财选A股 + X板块 + 今日涨幅排名前N |
| 今日最强板块中的前排股 | Step1: sector 查今日涨幅/成交额TOP1板块名。Step2: astock + 该板块名 + 条件 |

## 高风险词汇列表（不要在自动 prompt 中使用）

```text
热门   强势   主线   最强   爆发   捡漏   低位启动
未来   游资   机构抱团   值得关注   龙头（作为 sector 内查询）
```

---

## 注意

- **不要把"禁用"等同于"永远返回空"**。主线板块/可能爆发 在当前市场下有返回，但语义不可靠。
- "禁用"的判断标准是：**不能基于该问法自动生成可信的板块候选列表用于 pipeline 后续步骤**。
