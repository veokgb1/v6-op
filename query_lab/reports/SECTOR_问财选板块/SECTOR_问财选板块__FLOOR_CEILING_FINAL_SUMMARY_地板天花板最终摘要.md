## 1. 一句话结论

`问财选板块` 可以稳定作为“市场结构扫描器”使用：它适合返回板块/概念/行业指数列表，并附带部分指数字段；不适合直接问板块里的股票、龙头股、上涨原因。

实际成功路由是 `zhishu`，不是独立 `sector`。当前 adapter 的 `sector -> zhishu fallback` 是必要且正确的。

## 2. 地板：最短稳定问法

以下是当前最稳、可作为输入工坊/策略台模板的问法：

```text
今日涨幅大于3%的板块
今日涨幅排名前10的板块
今日成交额大于50亿的板块
今日成交额排名前10的板块
今日主力净流入为正的板块
今日主力净流入排名前10的板块
今日涨停家数大于3的板块
今日涨停家数排名前10的板块
今日上涨家数排名前10的板块
```

推荐生成格式：

```text
{时间窗口}{字段}{运算符}{阈值或排名}的板块
```

示例：

```text
近60日涨幅小于20%，今日涨幅大于3%的板块
今日涨停家数大于3的板块，今日主力净流入为正
```

## 3. 天花板：目前能承受的复杂度

已实测稳定：

- 单字段筛选稳定。
- 今日/今天 等价。
- 大于/超过 等价。
- 主力净流入/主力资金净流入 等价。
- 中文逗号分隔的 1-5 条组合稳定。
- 跨字段、跨时间窗口组合可用，例如 `近60日涨幅小于20% + 今日涨幅大于3%`。
- 情绪字段可用：涨停家数、上涨家数、换手率+涨停组合。

当前天花板结论：

```text
条件叠加至少 5 条稳定。
6-8 条未作为本轮正式上限确认，后续如需要可单独补测。
```

## 4. 返回内容：除了板块名还能返回什么

成功返回时，主要是 `sector_with_index_fields`，即板块列表 + 指数字段。

可用字段：

```text
指数代码
指数简称
指数@涨跌幅
指数@成交额
指数@主力资金流向
指数@涨停家数
指数@上涨家数
指数@换手率
指数@量比
指数@领涨股简称
```

解释：

- `指数简称` = 板块名。
- `指数代码` = 88xxxx / 884xxx / .TI 之类的板块指数代码，不是 A 股代码。
- `指数@涨停家数` / `指数@上涨家数` 在 query 含对应字段时出现。
- `指数@领涨股简称` 只有 query 含 `领涨股` 时出现。

## 5. 领涨股与龙头股

可用：

```text
今日涨幅排名前5的板块及其领涨股
```

这会返回：

```text
板块名 + 每个板块 1 只领涨股简称
```

限制：

- 只有 `领涨股` 能触发。
- `龙头股` 不触发领涨股列。
- 只返回股票简称，不返回股票代码。
- 每个板块最多观察到 1 只领涨股。
- `军工板块领涨股` 这类指定板块名 + 领涨股，直接失败。

## 6. 原因类追问

原因类不能用。

```text
上涨原因是什么
```

会直接导致 query 返回空。

```text
原因是什么
资金流入原因是什么
```

会被 pywencai 忽略，仍返回普通板块列表，没有原因列。

结论：

```text
不要自动生成“原因是什么 / 上涨原因是什么 / 资金流入原因是什么”。
```

## 7. 必须拆分的问题

以下不要在 `问财选板块` 一步完成：

```text
X板块龙头股
X板块中今日涨幅排名前N的股票
X板块中今日成交额排名前N的股票
今日最强板块中的前排股
今日涨幅TOP板块，然后查询每个板块中的TOP股票
```

推荐链路：

```text
Step 1 问财选板块:
  今日涨幅排名前5的板块

Step 2 问财选A股:
  {板块名}，今日涨幅大于3%的股票

Step 3 本地技能:
  kline / smc / wave / landmine
```

如果 Step 1 用了领涨股：

```text
今日涨幅排名前5的板块及其领涨股
```

则可以把 `领涨股简称` 作为人工参考或后续 astock 名称查询入口，但要注意简称可能重名。

## 8. 禁止自动生成

以下写法禁止进入自动模板：

```text
热门板块
强势板块
最强板块
主线板块
可能爆发的板块
哪些板块值得关注
上涨原因是什么
原因是什么
资金流入原因是什么
龙头股
指定板块名+领涨股
板块内今日涨幅前N股票
两步嵌套问法
```

其中：

- `热门/强势/最强` 多数直接空。
- `主线/可能爆发/值得关注` 有时返回，但语义不可信。
- `原因` 类没有原因字段。
- `龙头股` 不等于 `领涨股`。

## 9. 产品接法

策略台/输入工坊可以把 `问财选板块` 做成结构化矩阵：

```text
时间窗口：今日 / 近5日 / 近20日 / 近60日
字段：涨幅 / 成交额 / 主力净流入 / 涨停家数 / 上涨家数 / 换手率 / 量比
关系：大于 / 小于 / 排名前N / 为正
阈值：用户填写
可选增强：及其领涨股
```

返回后：

```text
板块名 -> Phase B / 问财选A股
指数代码/行情字段 -> 策略台展示
领涨股简称 -> 人工参考或后续 astock 名称查询
空结果/原因类/龙头类 -> 不进入 pipeline
```
