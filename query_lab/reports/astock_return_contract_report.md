## 核心问题答案

### 1. 默认返回是否只有代码？

**不是。** 默认必然包含以下 5 个字段：

| 字段 | 含义 | 类型 |
|------|------|------|
| `股票代码` | A 股代码（6位），带市场后缀 .SH/.SZ/.BJ | 必返回 |
| `股票简称` | 股票中文简称 | 必返回 |
| `最新价` | 当日最新价格 | 必返回 |
| `market_code` | 市场代码（151=BJ等） | 必返回 |
| `code` | 纯6位数字代码（不含市场后缀） | 必返回 |

### 2. 是否有中文股票名？

**有，始终有。** `股票简称` 是 pywencai 返回的固定字段，8/8 条均存在。

### 3. 哪些情况下会带价格/成交额/涨跌幅等字段？

#### 默认附带字段（所有 query 均出现）

| 字段名 | 含义 |
|--------|------|
| `最新价` | 当日最新价（实时/盘后） |
| `今日涨跌幅` 或 `涨跌幅:前复权[日期]` | 今日涨跌幅（视 query 写法有两种形式） |

> **涨幅写法差异**：含"今日涨幅"条件时返回 `今日涨跌幅`（百分比数字）；含"涨幅大于"条件时有时返回 `涨跌幅:前复权[date]`（前复权日涨幅）。两者含义相同但字段名不同。

#### 条件触发字段（query 中出现该字段时才会出现在返回列）

| query 条件 | 新增返回字段 |
|-----------|------------|
| 成交额大于N亿 | `成交额[日期]`、`成交量[日期]` |
| 换手率大于N% | `换手率[日期]`、`成交量[日期]`、`成交额[日期]` |
| 量比大于N | `量比[日期]`、`成交量[日期]` |
| 主力净流入大于N亿 | `主力资金净流入[日期]`、`净流出金额[日期]`、`净流入金额[日期]` |
| 流通市值在N到M之间 | `a股市值(流通股价格)[日期]`、`总市值[日期]`、`同花顺行业` |
| 板块名前缀（如"半导体板块"） | `同花顺行业`、`所属行业`（及更多额外字段，见下） |

#### 涨幅条件还额外触发 OHLC

当 query 含"涨幅"或多条件组合时，pywencai 会附带完整当日行情：

| 字段 | 含义 |
|------|------|
| `开盘价:前复权[日期]` | 当日开盘价（前复权） |
| `最高价:前复权[日期]` | 当日最高价 |
| `最低价:前复权[日期]` | 当日最低价 |
| `收盘价:前复权[日期]` | 当日收盘价 |

#### 板块前缀（AR-007）触发最多额外字段

AR-007 "半导体板块，今日涨幅大于3%" 返回 17 列，包含：
- `dde大单净额` — DDE 机构大单净额
- `总股本[日期]` — 总股本
- `市盈率(pe)[日期]` — 市盈率
- `所属行业` — 同花顺行业分类（完整名称）
- 全套 OHLC 前复权字段

### 4. 返回内容能否用于策略台/报告中心展示？

**可以，且强烈建议利用。** 当前 adapter 只提取代码，丢弃了所有其他字段。后续策略台/报告中心可以直接从 pywencai 结果中提取：

| 展示场景 | 可直接提取的字段 |
|---------|----------------|
| 候选池展示（名称+代码） | `股票代码` + `股票简称` |
| 候选池 + 今日涨跌 | + `最新价` + `今日涨跌幅` |
| 动量池 | + `成交额[日期]` + `换手率[日期]` + `量比[日期]` |
| 资金池 | + `主力资金净流入[日期]` |
| 行业池 | + `同花顺行业` + `所属行业` |
| 全量行情 | + OHLC 四价 + 成交量 |

**无需额外 quote API 调用**即可获得上述字段（当 query 包含对应条件时）。

### 5. 后续 pipeline 应提取哪些字段？

推荐提取字段（从 raw rows 而非当前 adapter codes 列表中提取）：

```text
必提取（存在于每条 query 结果）：
  股票代码      → normalized code (e.g. 000001.SZ)
  股票简称      → display name
  最新价        → latest price
  今日涨跌幅    → today's % change (when present)

条件相关（按 query 内容动态提取）：
  成交额[日期]   → volume amount
  换手率[日期]   → turnover rate
  量比[日期]     → volume ratio
  主力资金净流入[日期] → main force net inflow
  同花顺行业     → THS industry name
```

### 6. 是否还需要额外补测？

建议补测以下 3 类（可新增 A17 组）：

| 补测类型 | 建议 query | 目的 |
|---------|-----------|------|
| 技术形态 | "今日收盘价站上5日均线" | 确认均线条件是否触发价格/均线字段 |
| 代码查询 | "股票代码为000001" | 确认代码查询时返回什么字段 |
| 股票简称查询 | "通鼎互联，今日涨幅" | 确认从 sector 领涨股接 astock 的可行性 |

## 对现有 Adapter 的影响

当前 `wencai_astock_adapter.py` 的 `query()` 方法只返回 `codes: list[str]`，丢弃了所有其他字段（股票简称、最新价、条件字段）。

**建议**：在 adapter 中增加 `rows` 字段（原始行数据），或增加 `stock_names`、`quote_fields`、`factor_fields` 的提取，供后续策略台直接使用，避免重复调用 quote API。

**不建议**：现在改 adapter（会影响 A1-A15 已有测试基线）。可在 V6-OP 应用层增量处理。
